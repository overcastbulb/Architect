# Architect AI

> AI-powered architecture design platform that generates zoning-aware building concepts from natural language prompts.

**Live Demo:** https://architect-ai-startup.vercel.app

---

## What It Does

Architect AI converts a natural language building idea into:
- Structured building parameters extracted by AI
- A zoning feasibility report based on real municipal regulations
- A generated floor plan layout
- A 3D building mass visualization
- A downloadable PDF report

---

## Demo

1. Enter a real address anywhere in India
2. View real zoning constraints instantly (FSI, height, setbacks)
3. Describe your building concept in plain English
4. Click Generate
5. Get AI reasoning, compliance report, floor plan, 3D model and PDF export

---

## Features

- **Real Address Search** — Nominatim (OpenStreetMap), no API key required
- **10 City Zoning Database** — Real data from PMRDA, BMC, DDA, BBMP, HMDA, CMDA, AUDA, SUDA, NMC, CIDCO
- **AI Zone Inference** — Groq LLM estimates constraints for any other Indian city
- **Site Constraint Engine** — Shows real FSI, height, setback limits before generation
- **AI Reasoning Panel** — Plain English explanation for every zoning rule check
- **AI Verdict** — Overall feasibility summary generated by LLM
- **Floor Plan Generator** — Room-by-room layout with dimensions and area
- **3D Building Visualization** — Interactive Three.js massing model with orbit controls
- **Leaflet Map** — Pin drop on exact plot location
- **PDF Export** — Downloadable zoning report with all AI reasoning included
